## Behavior

Reduce the runtime mechanism atlas size without changing its decoded scanlines or non-IDAT PNG chunks.

## Implementation

public/assets/world/mechanisms.png decreases from 635125 to 209156 bytes. scripts/repack_png_lossless.mjs concatenates and inflates IDAT data, tries level-9 zlib strategies, replaces the compressed stream, computes CRC and writes only when --write is supplied and the result is smaller. It rejects animated PNG input.

## Scope and limitations

The lossless claim follows the repacker implementation; no new pixel comparison was run for this documentation. This commit changes compression and adds an authoring utility, not the atlas artwork or gameplay logic.
